# Pasos para descargar este proyecto

## Descargar Node.js ver. 18.17.1

- sudo apt get update
- sudo apt get install nodejs

## Opcional y mejor, descargar NVM y con eso descargar Node.js

- sudo apt install curl
- curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.39.5/install.sh | bash
- nvm -v (para ver si se descargo bien)
- nvm install 18.17.1

## Descargar repo

git clone https://github.com/Lanzallamas-FaMAF/Front.git
